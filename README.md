# Auto List Datenschutzhinweise

Statische technische Datenschutzhinweise für die interne eBay-Anwendung Tistou Auto List.

Die Hinweisseite liegt in `privacy.html`; `.nojekyll` deaktiviert die Jekyll-Verarbeitung bei GitHub Pages.
Dieses Repository enthält ausschließlich öffentliche Hinweise, keine Verkaufsdaten oder Zugangsdaten.
Es stellt keinen eBay-Callback und keine Verkäufer-Automatisierung bereit.

Kontakt über das [eBay-Verkäuferprofil tissten-0](https://www.ebay.de/usr/tissten-0).
